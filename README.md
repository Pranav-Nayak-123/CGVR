# CGVR

Computer Graphics and Virtual Reality lab records.

## Experiments

1. `experiments/01_opengl_bouncing_triangle/main.py` - OpenGL bouncing triangle animation.
2. `experiments/02_dda_line/dda.py` - DDA line drawing algorithm with an auto-scaled graph.
3. `experiments/03_bresenham_line_algorithm/bresenham_line.py` - Bresenham line algorithm with printed coordinate points.
4. `experiments/04_bresenham_line_graph/bresenham_line_graph.py` - Bresenham line algorithm with an auto-scaled graph.
5. `experiments/05_midpoint_circle_algorithm/midpoint_circle.py` - Midpoint circle drawing algorithm with an auto-scaled graph.
6. `experiments/06_2d_transformations/transformations_2d.py` - 2D translation, rotation, scaling, and reflection using homogeneous coordinates.
7. `experiments/07_composite_transformations/composite_transformations.py` - Composite transformations built by multiplying homogeneous matrices into a single matrix.
8. `experiments/08_cohen_sutherland_line_clipping/cohen_sutherland_line_clipping.py` - Cohen-Sutherland line clipping with a graphical result.
9. `experiments/09_opengl_vertex_fragment_shaders/vertex_fragment_shaders.py` - Rotating RGB triangle using GLSL vertex and fragment shaders with uniforms and switchable colour modes.
