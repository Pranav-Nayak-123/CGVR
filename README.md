# CGVR

Computer Graphics and Virtual Reality lab records.

## Experiments

0. `experiments/Exp0/main.py` - OpenGL bouncing triangle animation.
1. `experiments/Exp1/dda.py` - DDA line drawing algorithm with an auto-scaled graph.
2. `experiments/Exp2/bresenham_line.py` - Bresenham line algorithm with printed coordinate points.
3. `experiments/Exp3/bresenham_line_graph.py` - Bresenham line algorithm with an auto-scaled graph.
4. `experiments/Exp4/midpoint_circle.py` - Midpoint circle drawing algorithm with an auto-scaled graph.
5. `experiments/Exp5/transformations_2d.py` - 2D translation, rotation, scaling, and reflection using homogeneous coordinates.
6. `experiments/Exp6/composite_transformations.py` - Composite transformations built by multiplying homogeneous matrices into a single matrix.
7. `experiments/Exp7/cohen_sutherland_line_clipping.py` - Cohen-Sutherland line clipping with a graphical result.
8. `experiments/Exp8/z_buffer.py` - Z-buffer algorithm for hidden surface removal, with and without the depth test and the depth buffer shown side by side (lab manual Experiment 6).
9. `experiments/Exp9/phong_illumination.py` - Phong illumination model on a sphere, showing the ambient, diffuse, and specular terms and their sum (lab manual Experiment 7).
10. `experiments/Exp10/viewing_pipeline_3d.py` - 3D viewing pipeline from modeling coordinates to the screen, with perspective and orthographic projection, clipping, and viewport mapping (lab manual Experiment 10).
